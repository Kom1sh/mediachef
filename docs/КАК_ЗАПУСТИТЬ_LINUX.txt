MediaChef 0.7.1 (Linux x86_64)
==============================

ВАРИАНТ 1 — AppImage (любой дистрибутив)
----------------------------------------
    chmod +x MediaChef_0.7.1_amd64.AppImage
    ./MediaChef_0.7.1_amd64.AppImage
(нужен libfuse2: sudo apt install libfuse2)

ВАРИАНТ 2 — deb (Ubuntu/Debian)
-------------------------------
    sudo apt install ./MediaChef_0.7.1_amd64.deb

ЗАВИСИМОСТИ
-----------
Ставить ffmpeg и whisper.cpp не нужно: они уже внутри приложения (в AppImage и
в deb-пакете). Модели скачиваются в самом приложении (вкладка «Модели»).

Для продвинутых: подменить встроенные движки своими сборками можно переменными
окружения MEDIACHEF_FFMPEG, MEDIACHEF_FFPROBE, MEDIACHEF_WHISPER — в каждой
полный путь к бинарнику.

---

EN: AppImage → chmod +x && run (needs libfuse2). Or: sudo apt install ./MediaChef_*.deb
No dependencies: FFmpeg and Whisper ship inside the app; models are downloaded
inside it (Models tab). Advanced: MEDIACHEF_FFMPEG / MEDIACHEF_FFPROBE /
MEDIACHEF_WHISPER (full path to a binary) override the bundled engines.

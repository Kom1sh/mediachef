MediaChef 0.6.1 (macOS, Apple Silicon)
======================================

ПЕРВЫЙ ЗАПУСК — СНЯТИЕ КАРАНТИНА
--------------------------------
Приложение не подписано сертификатом Apple (подпись — $99/год, появится к публичному
релизу), поэтому macOS ставит на скачанный файл «карантин» и пугает при открытии.

Способ 1 (обычно достаточно):
  1. Перетащи MediaChef.app в «Программы» (или любую папку).
  2. Клик ПРАВОЙ кнопкой по MediaChef.app → «Открыть».
  3. В диалоге снова нажми «Открыть». (Понадобится один раз.)

Способ 2 (если система всё равно блокирует — «повреждено» и т.п.):
  Открой Терминал и выполни:
      xattr -cr /Applications/MediaChef.app
  (замени путь, если положил приложение в другое место), затем открой как обычно.

ТРЕБОВАНИЯ
----------
Ничего доустанавливать не нужно: FFmpeg и Whisper уже внутри приложения.
Модели распознавания речи скачиваются прямо из приложения (вкладка «Модели»).

Для продвинутых: подменить встроенные движки своими сборками можно переменными
окружения MEDIACHEF_FFMPEG, MEDIACHEF_FFPROBE, MEDIACHEF_WHISPER — в каждой
полный путь к бинарнику.

---

FIRST LAUNCH — REMOVING QUARANTINE (EN)
---------------------------------------
The app is not notarized by Apple yet, so macOS quarantines the download.

Way 1: Right-click MediaChef.app → "Open" → "Open" (needed once).
Way 2 (if still blocked): run in Terminal:
      xattr -cr /Applications/MediaChef.app

Nothing else to install: FFmpeg and Whisper ship inside the app.
Speech models are downloaded inside the app (Models tab).
Advanced: MEDIACHEF_FFMPEG / MEDIACHEF_FFPROBE / MEDIACHEF_WHISPER (full path to
a binary) override the bundled engines.

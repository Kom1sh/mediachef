MediaChef 0.5.0 (Windows x64)
=============================

УСТАНОВКА
---------
1. Запусти MediaChef_0.5.0_x64-setup.exe.
2. SmartScreen может предупредить (установщик пока не подписан):
   «Подробнее» → «Выполнить в любом случае».
3. WebView2 (движок интерфейса) установщик подтянет сам, если его нет.

ЗАВИСИМОСТИ
-----------
Их нет: FFmpeg и Whisper уже внутри приложения — ни ffmpeg в PATH, ни отдельный
whisper-cli.exe не нужны. Модели скачиваются в самом приложении (вкладка «Модели»).

Для продвинутых: подменить встроенные движки своими сборками можно переменными
окружения MEDIACHEF_FFMPEG, MEDIACHEF_FFPROBE, MEDIACHEF_WHISPER — в каждой
полный путь к .exe.

---

INSTALL (EN)
------------
1. Run MediaChef_0.5.0_x64-setup.exe.
2. SmartScreen may warn (unsigned yet): "More info" → "Run anyway".
3. WebView2 is bootstrapped automatically if missing.

No dependencies: FFmpeg and Whisper ship inside the app. Models are downloaded
inside the app (Models tab).
Advanced: MEDIACHEF_FFMPEG / MEDIACHEF_FFPROBE / MEDIACHEF_WHISPER (full path to
an .exe) override the bundled engines.

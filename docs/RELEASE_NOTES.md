**MediaChef 0.8.3 — теперь есть куда сказать, что не так.**

Раньше кнопка «Обратная связь» открывала почтовое письмо. На свежей Windows и на Linux почтового клиента нет, и нажатие не делало ничего — человеку, у которого что-то не сработало, из окна было некуда пойти.

Теперь обратная связь — форма на сайте: открывается в браузере, регистрация не нужна. К ней ведут три пути:

- в карточке упавшей задачи — «Сообщить об ошибке», версия, система и первая строка ошибки уже подставлены;
- в настройках — «Обратная связь»;
- после третьей успешной задачи один раз появится полоса с вопросом, пригодился ли MediaChef, с кнопками «Написать отзыв» и «Звезда на GitHub». Любая кнопка, включая крестик, убирает её навсегда.

Приложение само по-прежнему ничего не отправляет. В браузер уходят только версия, система и контекст — ни имён файлов, ни путей. Текст пишете вы, отправку нажимаете вы.

Из 0.8.1 без изменений: после обновления macOS считает MediaChef новым приложением — приложение само снимет старые записи разрешений и покажет системные диалоги: включить «Универсальный доступ» в списке и перезапустить, затем «Разрешить» микрофон при первой диктовке.

---

Обновление ставится само: приложение проверяет новую версию при запуске и предлагает установить.

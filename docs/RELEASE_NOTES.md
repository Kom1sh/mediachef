**MediaChef 0.5.0 — приложение на десяти языках.**

Интерфейс переведён на английский, русский, испанский, португальский, французский, немецкий, польский, итальянский, арабский и китайский. Язык выбирается в «Настройках» или берётся из системы: региональный вариант приводится к языку, так что pt-BR — это португальский, а zh-Hans — китайский. Для арабского вся раскладка разворачивается справа налево.

Названия рецептов, их описания и слова, по которым работает поиск, пока остаются на английском и русском — это следующий шаг, он требует перестройки схемы каталога.

Сайт mediachef.app тоже переведён на все десять языков, у каждого своя посадочная с собственным адресом.

Функционально по сравнению с 0.4.1 ничего не изменилось: движки, рецепты, модели и очередь те же.

Первый запуск — как раньше (сборки пока без подписи):
- **macOS**: правый клик → «Открыть», либо `xattr -cr /Applications/MediaChef.app` — инструкция внутри архива.
- **Windows**: SmartScreen → «Подробнее» → «Выполнить в любом случае».

Размеры прежние: mac-архив ~60 МБ, dmg ~66 МБ, Windows-установщик ~82 МБ, AppImage ~181 МБ, deb ~118 МБ.

Для продвинутых: подменить встроенные движки своими сборками можно переменными окружения `MEDIACHEF_FFMPEG` / `MEDIACHEF_FFPROBE` / `MEDIACHEF_WHISPER`. Лицензии и точные версии встроенных компонентов — в NOTICE.md (в архивах и среди файлов релиза).

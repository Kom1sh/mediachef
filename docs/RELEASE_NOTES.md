**MediaChef 0.8.7 — на Windows больше не всплывают чёрные окна, а расшифровка идёт быстрее.**

На Windows вместе с каждой конвертацией и расшифровкой открывалось пустое чёрное окно консоли. Если его закрыть, задача обрывалась — например, расшифровка часовой записи на середине с ошибкой «whisper exited with code -1073741510». При диктовке такое окно ещё и уводило фокус из поля, куда печатается текст. Теперь программа работает без лишних окон на всех трёх системах.

Расшифровка стала быстрее на компьютерах с большим числом ядер: Whisper раньше всегда считал в четыре потока, теперь берёт столько, сколько есть ядер, но не больше восьми. На восьмиядерном процессоре это примерно вдвое быстрее.

Спасибо человеку, который прислал отчёт об ошибке через форму на сайте: по приложенному к нему журналу причину нашли за один вечер.

Из 0.8.1 без изменений: после обновления macOS считает MediaChef новым приложением — приложение само снимет старые записи разрешений и покажет системные диалоги: включить «Универсальный доступ» в списке и перезапустить, затем «Разрешить» микрофон при первой диктовке.

---

Обновление ставится само: приложение проверяет новую версию при запуске и предлагает установить.

**MediaChef 0.7.0 — обновляется сам, ставится пакетным менеджером.**

До этой версии установленная копия не могла узнать, что вышла новая: скачал один раз — и живёшь с той сборкой, пока сам не зайдёшь на страницу релизов. Теперь приложение спрашивает про обновления при запуске и предлагает поставить найденное одной кнопкой. В «Настройках» появилась строка с версией и кнопкой проверить вручную.

Проверка при запуске молчит, если ответить нечего: нет сети, приложение поставлено из deb или запущено из исходников — обо всём этом вы не спрашивали, и сообщения не будет. Вслух отвечает только кнопка в настройках.

Перезапуск после установки — ваш: если в очереди идёт расшифровка, обновление её не оборвёт и дождётся, пока вы нажмёте сами.

Пакет обновления подписан. Приложение носит открытую половину ключа и не примет ничего, подписанного чужой, — подменить обновление по дороге нельзя.

**Появились нормальные способы установки.**

macOS:

    brew tap kom1sh/mediachef https://github.com/Kom1sh/mediachef
    brew install --cask mediachef

Windows:

    winget install Kom1sh.MediaChef

Там же, для Windows, появилась портативная поставка — тот же набор файлов, что кладёт установщик, но распакованный: пригодится, если SmartScreen не даёт запустить неподписанный инсталлятор. Из неё же ставится Scoop:

    scoop bucket add mediachef https://github.com/Kom1sh/mediachef
    scoop install mediachef

Подписи Apple и Microsoft у сборок пока нет, так что macOS по-прежнему может сказать, что приложение повреждено — команда для снятия карантина лежит в КАК_ОТКРЫТЬ.txt внутри архива и в подсказке Homebrew.

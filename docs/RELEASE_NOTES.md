**MediaChef 0.4.0 — движки внутри всех дистрибутивов.**

FFmpeg, FFprobe и Whisper теперь едут внутри каждой поставки — macOS (.app в dmg и zip), установщик Windows, Linux AppImage и deb. Доустанавливать не нужно ничего: ни ffmpeg в PATH, ни отдельный whisper-cli. Встроенные движки имеют приоритет над системными — даже если ffmpeg уже стоит через Homebrew, приложение работает на своих, проверенных сборках.

Модели распознавания речи по-прежнему скачиваются в самом приложении (вкладка «Модели») и в поставку не входят.

Первый запуск — как раньше (сборки пока без подписи):
- **macOS**: правый клик → «Открыть», либо `xattr -cr /Applications/MediaChef.app` — инструкция внутри архива.
- **Windows**: SmartScreen → «Подробнее» → «Выполнить в любом случае».

Размеры закономерно выросли (теперь всё включено): mac-архив ~60 МБ, dmg ~66 МБ, Windows-установщик ~82 МБ, AppImage ~181 МБ, deb ~118 МБ.

Для продвинутых: подменить встроенные движки своими сборками можно переменными окружения `MEDIACHEF_FFMPEG` / `MEDIACHEF_FFPROBE` / `MEDIACHEF_WHISPER`. Лицензии и точные версии встроенных компонентов — в NOTICE.md (в архивах и среди файлов релиза).

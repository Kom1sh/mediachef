**MediaChef 0.4.1 — новая палитра.**

Приложение перекрашено: вместо тёплой бежевой гаммы — холодные нейтрали, один насыщенный зелёный на главные действия и янтарь на то, что выполняется прямо сейчас. Светлая тема стала светлее и контрастнее, тёмная — графитовой вместо коричневой. Сайт mediachef.app теперь выглядит так же.

Заодно поправлен контраст: белая подпись на зелёной кнопке давала 3.39:1 при норме WCAG AA 4.5:1 — зелёный опущен до нужного уровня, подпись читается. Рамки полей, полоса прогресса и знаки на плитках категорий проверены расчётом и проходят свои пороги (3:1 для нетекстовых элементов, 4.5:1 для текста).

Функционально ничего не изменилось: движки, рецепты, модели и очередь — как в 0.4.0.

Первый запуск — как раньше (сборки пока без подписи):
- **macOS**: правый клик → «Открыть», либо `xattr -cr /Applications/MediaChef.app` — инструкция внутри архива.
- **Windows**: SmartScreen → «Подробнее» → «Выполнить в любом случае».

Размеры прежние: mac-архив ~60 МБ, dmg ~66 МБ, Windows-установщик ~82 МБ, AppImage ~181 МБ, deb ~118 МБ.

Для продвинутых: подменить встроенные движки своими сборками можно переменными окружения `MEDIACHEF_FFMPEG` / `MEDIACHEF_FFPROBE` / `MEDIACHEF_WHISPER`. Лицензии и точные версии встроенных компонентов — в NOTICE.md (в архивах и среди файлов релиза).
